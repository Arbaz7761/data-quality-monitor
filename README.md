\# 🤖 AI-Powered Data Quality Monitor



An intelligent data quality monitoring agent that automatically detects 

data issues and generates plain-English diagnostic reports.



\## 🚀 Tech Stack

\- Python 3.11+

\- Pandas

\- NumPy

\- Anthropic Claude API

\- Pytest



\## 📋 Features

\- ✅ Automatic null/missing value detection

\- ✅ Outlier detection using Z-score

\- ✅ Duplicate row detection

\- ✅ Schema validation

\- ✅ Automated alerts for critical issues

\- ✅ Plain-English report generation

\- ✅ Unit tested with pytest



\## ⚙️ How to Run



1\. Clone the repository:

git clone https://github.com/Arbaz7761/data-quality-monitor.git



2\. Create virtual environment:

python -m venv venv

venv\\Scripts\\activate



3\. Install dependencies:

pip install -r requirements.txt



4\. Add your API key to .env:

ANTHROPIC\_API\_KEY=your\_key\_here



5\. Run the monitor:

python main.py



\## 🧪 Run Tests

pytest tests/ -v
